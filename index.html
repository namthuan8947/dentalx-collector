Hướng Dẫn Hoàn Thành Trọn Gói Bài Tập Bằng AI

1
Chia Sẻ Form Cho Nhóm

Đẩy trang web này lên GitHub Pages hoặc gửi file Excel cho các bạn trong nhóm điền: Họ tên, MSSV, Nhóm, tài khoản và mật khẩu DentalX.

2
Lấy Prompt / Xuất Excel

Tại mỗi bạn trong bảng danh sách, nhấn nút "Copy Prompt" (hoặc xuất toàn bộ ra file Excel để quản lý tập trung).

3
Dán Vào Antigravity

Dán câu lệnh vào chat với AI. AI sẽ tự động đăng nhập DentalX của bạn đó, tự sinh bệnh nhân, tạo doanh thu, in bệnh án và xuất file Word hoàn chỉnh.
